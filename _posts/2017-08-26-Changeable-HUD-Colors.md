Now with support for III (full) and SA (limited inbuilt color adjustment support) in addition to VC! Supports v1.0 exes only for all games.

<!--more-->

### Features:
- Update most HUD element colors (III/VC).
- Update most HUD shadow colors (III/VC).
- Built-in Color randomizer (III/VC/SA).
- Update inbuilt color values (SA).
- Preset configurations: `LCS.ini`, `IV.ini`, `V.ini`, `VCS.ini`, `SA.ini`.

### Configurable Colors (III/VC Sample):
```ini
[Colors]
MoneyColor=89 115 150 255
HealthColor=186 101 50 255
HealthIconColor=186 101 50 255
ArmorColor=124 140 95 255
ArmorIconColor=124 140 95 255
WantedActiveColor=193 164 120 255
ZoneColor=152 154 82 255
VehicleColor=194 165 120 255
TimeColor=194 165 120 255
```
